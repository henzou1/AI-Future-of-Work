# AI & the Future of Work

An interactive website exploring how artificial intelligence is changing the world of work — from current developments and future jobs to the skills people may need in the coming years.

## About the project

This project was created as an exploration of AI, technology and the future of work.

The website combines research, interactive elements, visual design and JavaScript-based tools to make a complex topic easier to explore.

Instead of presenting AI as either purely positive or purely negative, the project looks at different aspects of the topic and lets users explore the information themselves.

## Features

- Interactive exploration of AI and the future of work
- Future jobs section
- Interactive Job Checker
- Vocabulary / glossary
- Sources and research
- English and German language support
- Responsive design for different screen sizes
- Custom visual design and animations

## Project structure

The project consists of 13 main files:

- `index.html` — Main page
- `style.css` — Main stylesheet
- `script.js` — General website functionality
- `imprint.html` — Imprint
- `vocabulary.html` — AI and work vocabulary
- `making-of.html` — Documentation of the development process
- `future-jobs.html` — Future jobs section
- `sources.html` — Sources and references
- `job-checker.html` — Interactive Job Checker
- `job-data.js` — Job data
- `job-checker.js` — Job Checker functionality
- `job-content.js` — Job-related content
- `job-english.js` — English job content

## Running the project locally

Because the project is primarily built with HTML, CSS and JavaScript, it can be opened locally by opening `index.html` in a web browser.

For the best experience, however, the project can be hosted using GitHub Pages or another static web host.
