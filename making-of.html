Project documentation

Making of

This page documents how the website was planned, designed and built — including the role of AI as a development and writing assistant. The goal was not simply to make a website, but to create a clear, research-based digital project about AI and the future of work.

01

The idea

The project started with a simple question: how is artificial intelligence changing work, and what could that mean for different professions? The website was designed to turn that broad topic into something interactive and easy to explore.

02

Research and structure

The content was organised around several sections: a general introduction to AI, future jobs, a vocabulary section, sources and a profession-focused Job Checker. This structure connects background information with concrete examples.

03

Design

The visual direction combines editorial design with technology-focused details. The aim was a professional interface with strong typography, generous spacing, subtle motion, restrained colour use and clear hierarchy instead of a typical school-project look.

04

Building the website

The website was built as a static project using HTML, CSS and JavaScript. The system was developed so that theme, language switching, navigation, animations and the Job Checker work directly in the browser without a separate backend.

HTML CSS JavaScript GitHub Pages
05

The Job Checker

The Job Checker uses a database of 1,260 professions with estimated potential AI impact values. Search supports German and English terms, aliases and common typing mistakes. Results distinguish between the profession itself and the tasks that AI could potentially influence.

The important idea behind the checker: a high potential impact on tasks does not automatically mean that a profession will disappear.

06

AI as a tool

AI was used as a development and writing assistant during the project. It helped with code, structure, wording, debugging and ideas. The project was still reviewed, tested and adjusted manually throughout the process.

07

Testing

A large part of the work happened after the first version was already functional: language switching, dark mode, search behaviour, fuzzy matching, mobile layouts, result cards and the many small interactions were tested and corrected repeatedly.

08

A few lines of the code

The site is built with ordinary browser technologies rather than a large framework. Some of the interesting parts are small: switching languages, storing the selected theme and calculating fuzzy search matches for the Job Checker.

JavaScript · language switching 
function setLanguage(language) {
    document
        .querySelectorAll("[data-en][data-de]")
        .forEach(element => {
            element.textContent =
                element.dataset[language];
        });

    document.documentElement.lang =
        language === "de" ? "de" : "en";
}

const distance =

        normalizedA,

const maxLength =
    Math.max(
        normalizedA.length,
        normalizedB.length

What this project is really about

The website is not meant to predict exactly which jobs will survive. It is meant to explore how AI can change tasks, workflows and required skills — and why the future of work is likely to involve both technological change and continued human decision-making.
